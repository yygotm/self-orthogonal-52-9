# 二進自己直交 [52,9,22] の不存在：計算機援用証明案

作成：2026/10/8。対象は二元線形符号、内積は通常の Euclidean 内積。

**得られた結論は d_SO(52,9)=20。** 以下に、数学的帰着・有限列挙・下界の生成行列を一つの検証可能な形にまとめた。独立した第三者による査読はまだ受けておらず、新規性も主張していない。Simonis の分類については出版元の要旨を確認した段階で、論文本文の証明は取得していない。

最終の排除計算は整数とビット演算による有限列挙。OR-Tools と SCIP の不可能判定は別の照合として残したが、証明の最終経路には使わない。

## 1. 三つの視点から何が変わったか

| 視点 | 実施内容 | 決着への寄与 |
|---|---|---|
| 既存の視点を拡張 | 固定 [51,8,24]+0 の拡張を三つ組構造で全列挙し、直交変換で得られる零列なしの例にも拡張 | 固定例の UNKNOWN を完全排除に変更した。 |
| 既存の考え方を疑う | 「巨大な一般分類が先に必要」という前提を検討し、最大重みと wt/4 mod 2 の3次関数から場合を絞った | 二重偶 [52,8,24] 全体を3種類へ帰着する分類ができた。 |
| 別の方法を探す | Fourier/Walsh 変換、Reed–Muller 最小語、低変数 bent 関数、合同式の消去を組み合わせた | 49個の持ち上げ問題を5,318候補、重み40を8,448候補の整数列挙で排除できた。 |

別の同値問題として「同じ非零列を2本持つ二重偶 [54,9,24] の存在」も得た。公開 [54,9,24] の全重み6変換も試したが、この経路は最終証明には不要。

## 2. 用いる既知の結果と確認範囲

1. 一般の二元線形符号の上界 d(52,9)=22、d(52,8)=24。データベースの原ページを確認した。[52,9](https://www.codetables.de/BKLC/BKLC.php?q=2&n=52&k=9)、[52,8](https://www.codetables.de/BKLC/BKLC.php?q=2&n=52&k=8)
2. Bouyukliev–Bouyuklieva, *Classification of linear codes using canonical augmentation* (2019), **Table 8**：n(8,24)=51、[51,8,24] は1同値類。原文を確認した。[原文](https://arxiv.org/html/1907.10363)
3. Kurz, *Classification of 8-divisible binary linear codes with minimum distance 24*, **Proposition 1(1), Table 4**：重み集合 {24,32}、次元8の符号に、有効長52のものはない。原文を確認した。ここで長さは零列を除いた有効長。[原文PDF](https://d-nb.info/1223982076/34)
4. Simonis, *A description of the [16,7,6] codes* (1991), LNCS 508, pp.24–35：二元線形 [16,7,6] は3同値類。**出版元要旨で確認、本文・定理番号は未確認**。本調査では異なる重み分布を持つ3例を構成し、全語で検算して代表に用いた。[出版元](https://link.springer.com/chapter/10.1007/3-540-54195-0_36)
5. RM(r,m) の最小重みは 2^(m−r)、最小語の台は余次元rのアフィン部分空間。Carlet (2024), *Identifying codewords in general Reed-Muller codes and determining their weights*, **Section 2, p.10613** に記載された古典的結果を原文で確認した。[原文PDF](https://www.aimspress.com/aimspress-data/math/2024/5/PDF/math-09-05-518.pdf)

第4項の分類結果を仮定として切り離せば、ここに示す計算は全て添付コードで再現できる。4変数 bent 関数が二次以下である事実も、全65,536真理値表の検査で照合した。

## 3. まず二重偶部分符号へ帰着する

SO 符号 C 上では q(c)=wt(c)/2 mod 2 は線形。実際、

\[
\operatorname{wt}(x+y)=\operatorname{wt}(x)+\operatorname{wt}(y)-2|\operatorname{supp}(x)\cap\operatorname{supp}(y)|
\]

で、自己直交性により最後の交差数は偶数。

仮に SO [52,9,22] が存在すると、q は非零。q=0 なら二重偶で最小重み24以上となり、一般の [52,9] 上界22に反する。したがって

\[
D=\ker q\quad\text{は二重偶 }[52,8,24]
\]

非自明な剰余類 C\D の256語は、全て重みが2 mod 4で、22以上でなければならない。

以下で D は次の3種類だけであることを示し、それらの拡張を全て排除する。

| 代表 | 零列 | 重み分布 |
|---|---:|---|
| D0 | 1 | 1+204z^24+51z^32 |
| D1 | 0 | 1+172z^24+32z^28+51z^32 |
| D2 | 0 | 1+174z^24+30z^28+49z^32+2z^36 |

代表行列は `D-representative-0.txt`、`D-representative-1.txt`、`D-representative-2.txt`。零列を持つ場合は、n(8,24)=51 と [51,8,24] の一意性から直ちに D0 に帰着する。

## 4. 最大重みを36以下にする

二重偶なので、24以上の候補重みは24,28,32,36,40,44,48,52。

### 重み52

全1語を基底の1本に選ぶと、残る7ビットで表した52列の多重度 m の Fourier 係数は F(0)=52、F(u)=±4（u≠0）。Parseval から Σm²=(52²+127·16)/128=37 となるが、非負整数性から Σm²≥Σm=52で矛盾する。

### 重み44

重み44語 c の外側8座標への射影は、核が {0,c} で次元7。他の核の語 x があれば wt(x)+wt(x+c)=44<48で矛盾する。外側は偶重みだから、射影は偶 [8,7,2] 全体。

外側重みを j とすると、内側44列の Fourier 係数は |F(u)|≤2j−4。非零メッセージの j=2,4,6,8 の個数は28,70,28,1なので、

\[
128\sum m^2\le44^2+70\cdot16+28\cdot64+144=128\cdot39<128\cdot44,
\]

となり矛盾する。

### 重み48

重み48語 c の外側4座標への射影は偶なので、核 K の次元 r は5以上。K の語は0,c以外全て重み24。c を全1の行として Fourier 変換すると列多重度が48/2^(r−1)となるので r=5。K は RM(1,4) の各座標を3回繰り返した符号。

外側重み2の語 x の K 剰余類では内側重みは22か26。各三つ組の重みを r_t、f(t)=3−2r_t とすると、16個の Walsh 係数は全て絶対値4。Parseval から各 r_t は1か2。

外側の基底1100,1010,1001の持ち上げを x,y,z とする。単独と2本の和は全て外側重み2なので、各三つ組で x,y,z の像は F2^3/〈111〉の3つの相異なる非零元。よって x+y+z は各三つ組で000か111。

その外側は1111で、K 剰余類の内側重みは20〜28の範囲、4と3の両方の倍数。したがって全て24となる。16ビットの真理値表が全てのアフィン関数から距離8になることを要求し、Walsh 係数が全て0となって矛盾する。

### 重み40：整数全列挙

外側への射影は偶 [12,7,4]。パリティ検査行列に全1行を選べるので、その12列は F2^4 の16アフィン点から4点を除いたもの。削除4点はアフィン平面型とアフィン独立型の2種類。

外側重み j に対して |F(u)|≤2j−8。Parseval の上界が Σm²≥40 の下界と一致するので、内側40列の多重度は0/1、全ての非自明係数は上界 ±(2j−8) に達する。

二重偶符号の関数 f(x)=wt(x)/4 mod 2 は3次以下。これは重みの包除展開で、1次項の重みは4の倍数、2次項の交差数は偶数、4次以上の係数は8の倍数になるため。

c と持ち上げ x(u) を基底に選び、a(u)=f(x(u)) とすると

\[
f(x(u)+c)+f(x(u))=j(u)/2\pmod2.
\]

j=4,8,12 で a(u)=0でなければならない。この条件を満たす7変数3次関数は両残余型とも次元8の線形空間。基底の持ち上げを c だけ変える7次元の同値操作で、各型2候補へ縮約できる。

各候補で F(u) の許される符号を入れ、逆 Walsh 変換で m が0/1になるか全列挙する。合同式による消去後の列挙数は4,096+4,096+256=8,448、残り1候補は合同式で直ちに矛盾し、解は0。

**コード：** `exact40.py`、`exact40-results.json`。以前の bent モデルと8分岐の整数計画モデルでも、OR-Tools・SCIP の両方が不可能と判定しており、異なる帰着による照合になっている。

## 5. 重み36を含む場合

重み36語 c の外側は偶 [16,7,6]。核は {0,c}、外側が4以下なら二つの語の重み和が48未満となる。用いる3代表は次の通り。

| 型 | ファイル | 重み分布 |
|---|---|---|
| B | `residual16-0.txt` | 1+45z^6+41z^8+34z^10+6z^12+z^14 |
| A | `residual16-1.txt` | 1+48z^6+30z^8+48z^10+z^16 |
| C | `residual16-2.txt` | 1+44z^6+45z^8+28z^10+10z^12 |

### B型とC型の排除

a(u)=wt(x(u))/4 mod 2 は7変数3次以下で、

\[
f(x(u)+c)=a(u)+1+j(u)/2\pmod2.
\]

j=6 では a=0。この線形条件を満たす3次関数空間の次元は B型18、C型19。全関数を列挙し、持ち上げの変更 a↦a+ℓ(u)(1+j(u)/2) と、検証済みの残余符号の座標置換で縮約する。

零列なしの D の同一列対数を b、重み36語数を A36 とすると、最初の2つのモーメントから

\[
A24=172+4b-A36,\quad A28=32-8b+3A36,\quad A32=51+4b-3A36
\]

なので、f の重みは N=32−8b+4A36。B型では A36≤8、かつ導関数から N≥48なので48≤N≤64。C型では A36≤11、N≥56なので56≤N≤76。

この範囲に残るのは B型3軌道、C型46軌道。各 a に対し内側重み i は

\[
24\le i+j\le36,\quad24\le36-i+j\le36,\quad i+j\equiv4a(u)\pmod8
\]

を満たす。選択肢は1個か、差8の2個。F(u)=36−2i とし、2択を z_u∈{0,1} で表すと、内側列多重度は逆 Walsh 変換

\[
m(v)=\frac{1}{128}\sum_u F(u)(-1)^{u\cdot v}
\]

で一意に復元される。整数性を mod 8 の線形合同式へ落とし、行消去で得た必要な F2 方程式の全解を列挙する。残る二値自由度は最大12、合計5,318候補で、非負整数多重度になるものは0。多重度の上限2を仮定しなくても0。

**コード：** `residual36_cubics.py`、`exact36.py`、`exact36-results.json`。OR-Tools・SCIP による49モデルも全て INFEASIBLE で一致した。

### A型の構造

外側の全1語の持ち上げとその c との差は、重み32と36。それ以外の外側語から36は出ないので、D の重み36語はちょうど2本。

内側36列の Parseval 上界は Σm²≤38となり、同一列対数 b≤1。従って f の重みは40−8bで、32か40。A型に適合する3次関数は65,536個を全列挙でき、重み40のものは0個（`audit_exact.py`）ので b=1、f の重みは32。

RM(3,8) の最小語の台はアフィン5次元空間なので、その方向部分空間 K の符号次元は5、K は8-divisibleで重み24か32。f=1の剰余類には重み28が30語、36が2語ある。

重み36語を v、そのもう1語を v+k0 と選ぶ。K の列型 p に対する、v のビットに符号を付けた列数の差は、p=0で−5、p≠0かつ k0·p=0で−1、k0·p=1で0。従って K の零列は5以上。一方 Griesmer 境界から K の有効長は47以上で、零列はちょうど5。

K は [47,5,24]、重み分布は1+30z^24+z^32。列型は、固定超平面の非零15点を1回ずつ、外側16点を2回ずつ、零を5回。v は15単列と零列では1、各二重列では0,1に正規化できる。

残り2行を構成する問題では、各二重列の一方の16ビットが4変数 bent 関数になる。もう一方と15単列を合わせた31ビットの Walsh 支持から、二つの4変数 bent 関数 B、B+h を得る。4変数 bent 関数は二次なので、有限の二次関数を全列挙できる。

K の加算で一次・定数項を消すと、第7行の候補は5,376個で、検証した座標置換により1軌道。第8行の候補は、既存7行の加算を除いて36個で、全て1軌道。したがってこの型の D は D2 の1種類だけ。

**コード：** `normalized36_orbits.py`、`normalized36-classification.json`。

## 6. 最大重み32の場合

f=wt/4 mod 2 が0なら8-divisibleとなり、零列なし有効長52は Kurz の Proposition 1(1) で除外される。f≠0なら最小重み32以上。

上記モーメント式に A36=0を代入すると wt(f)=32−8bなので、b=0、wt(f)=32。f=1の台はアフィン5次元空間、その方向の K は次元5で重み24か32、剰余類は全32語が重み28。

定重み剰余類の Fourier 変換から、K の非零列多重度は偶数、零列数は4以上。非零多重度を半分にして Griesmer 境界を使うと零列数は4以下となり、ちょうど4。半分にした符号は [24,5,12]、重み分布1+28z^12+3z^16。

その列多重度の整数性から、重み16を持つ3メッセージの和は0。従って24列は F2^5 の固定3次元部分空間 U の外側の全点。K はこれらを2回ずつ並べ、零列を4個加えた形に一意に正規化できる。

f=1の代表 v は、各二重列で0,1、零列4個で全1。残る2行の外側4ビットは重み2で、両者の交差数は1。

第7行を加えるとき、各対の2ビットが同じ場所と異なる場所に分けて Fourier 変換する。重み24/32の条件から、それぞれの Walsh 係数は2または−6。−6の支持は、F2^3 から F2^2 への関数のグラフ。その2成分と和は全て3変数 semi-bent、従って二次でなければならない。

二つの二次成分とアフィン部分を全列挙すると、第7行は344,064候補、K 加算を除くと10,752候補。検証済み座標置換で全て1軌道になる。第8行は7行の加算を除いて24候補、全て1軌道。従って D は D1 の1種類だけ。

**コード：** `normalized32_orbits.py`、`normalized32-classification.json`。自己同型群の完全な位数や既成の同値判定ソフトには依存せず、使用する置換が符号を保つことを実際に確認している。

## 7. 3種類からの9次元拡張を排除する

D0 の51非零座標は、生成行列の3列の和が0となる17個の三つ組に分かれる。v∈D0^⊥ の偶重み代表を、各三つ組で偶重みの部分 a、三つ組111の加算、最後の座標に一意分解する。

a の空間は、D0 による商を取ると18次元。三つ組111を加える17ビットにより最後の座標の偶奇も決まる。実際に符号と三つ組を保つ座標置換で18次元側を縮約すると23軌道。小さい巡回部分群だけでは695軌道となり、固定 D0 の独立な全探索にも用いた。

偶重み h に対する直交変換

\[
T_h(x)=x+(x\cdot h)h
\]

は内積を保つ。wt(h)=6なら、偶重み語の重み mod 4も保つ。D0 の零座標を含む重み6の h で距離24を保つものは29,376通り。D1 と D2 はこの中に含まれ、具体的にはビットマスク

```
h1 = 2251816993685511
h2 = 2251834173685767
```

を用いる。座標番号は0始まり、元の零座標は51。

T_h の前後で偶重み語の重み変化は−4,0,+4だけ。従って目標の拡張の逆像は、剰余類の最小重み18以上。23軌道を全て処理して、この条件を満たす代表985,908個を列挙した。各代表について29,376個の h のうち、

- 重み18の各語との交差が1。
- 重み22の各語との交差が5でない。

という必要十分条件を満たす h を調べ、0個だった。重み26以上は変換後も22以上なので追加条件は不要。

このため D1 と D2 からの目標拡張はない。D0 からの拡張も `triple_exhaustive.py` で全排除済み。D0 による偶重み商のうち2 mod 4の全 2^34+2^17 個を軌道のサイズで数え直し、範囲の一致を確認した。

**コード：** `triple_search.py`、`geometry.py`、`triple_exhaustive.py`、`joint_switch_search.py`。

## 8. 下界と結論

D0 に長さ52の全1行を加えれば SO [52,9,20]。全512語を検算すると

\[
W=1+51z^{20}+204z^{24}+204z^{28}+51z^{32}+z^{52}
\]

生成行列は `LOWER-52-9-20.txt`、階数9・自己直交性・最小距離20は `AUDIT.json` に記録した。

以上の帰着と列挙を合わせると、SO [52,9,22] は存在せず、**d_SO(52,9)=20**。

## 9. 再現・検証上の境界

- 通常の Python 整数、bit_count と NumPy の整数配列を使う。最終の分類・排除は時間制限付きソルバーの UNKNOWN を根拠にしない。
- `reproduce.py` は主要経路を順に実行して記録する。最終コードは Python 3.13 と NumPy 2.5.3 で実行した。NumPy は `bitwise_count` を使うため2系が必要。
- 合同式消去の実装は小さい320問題で直接総当たりと比較し、真の解を落とさないことを照合した。これは大きいケースの数学的帰着の代わりではなく、実装の照合。
- `AUDIT.json` は4変数の全真理値表、標準形から得た60行列、下界行列、全排除の件数を確認する。
- 第三者の独立再実装・数学的帰着の査読、Simonis 本文の確認は未実施。論文としての公開や新規性の主張は行っていない。
- `RESEARCH.md` は途中の UNKNOWN や不成功も残した探索記録。結論と証明の経路はこの `PROOF.md` を参照する。
