## 2. 用いる既知の結果と確認範囲

### 2.1. 最終経路に残る分類表

Sascha Kurz, *Classification of 8-divisible binary linear codes with minimum distance 24*, **Section 2, Table 1（PDF p.4）** を用いる。表の対象は、零列を除いた有効長 n、次元 k、最小距離24以上の 8-divisible 二元線形符号。k=8、n≤54 では g_2(8,32)=65>54 なので、8-divisible な符号の最小距離24以上と最小距離24は同じものを数える。k=8 行の n=51,52,53,54 の値は順に **1,0,0,1** で、用いるのは n=51 の一意性と n=52 の不存在だけ。表の直前には各行の左側の空欄は0を表すと明記されている。重み集合を {24,32} に制限した表ではなく、重複列も許される。[同梱PDF](references/kurz.pdf)、[取得元](https://d-nb.info/1223982076/34)、[出典・ハッシュ記録](references/SOURCES.md)

Table 1 と有効長の定義を原文で確認した。**表の分類計算自体は本調査・査読のいずれでも再計算していない**。Proposition 1(1) や Table 4 をこの2値の直接の引用箇所とした旧版の記述は訂正する。

### 2.2. 古典的結果と計算で確認した事項

## 3. まず二重偶部分符号へ帰着する

### 3.1. q の二つの場合を含めた帰着

SO 符号 C 上では q(c)=wt(c)/2 mod 2 は線形。実際、

\[
\operatorname{wt}(x+y)=\operatorname{wt}(x)+\operatorname{wt}(y)-2|\operatorname{supp}(x)\cap\operatorname{supp}(y)|
\]

で、自己直交性により最後の交差数は偶数。

仮に最小距離22以上の SO [52,9] 符号 C が存在するとする。まず q=0 の場合は二重偶 [52,9,≥24] なので、その非零重みは24,28,…,52に限られる。重み分布を A_w、双対の重み分布を B_j とし、長さ52の Krawtchouk 多項式を

\[
K_j(w)=\sum_s(-1)^s\binom ws\binom{52-w}{j-s}
\]

と置く。MacWilliams 恒等式は 512B_j=Σ_w A_w K_j(w)。F(w)=23K_1(w)+4K_2(w)+K_3(w) とすれば F(0)=28600で、

| w | 24 | 28 | 32 | 36 | 40 | 44 | 48 | 52 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| F(w) | −72 | −72 | −72 | −584 | −2120 | −5192 | −10312 | −17992 |

Σ_{w>0}A_w=511、A_w≥0、B_j≥0なので

\[
0\le512(23B_1+4B_2+B_3)
=28600+\sum_{w>0}A_wF(w)
\le28600-72\cdot511=-8192<0
\]

と矛盾する。これは **分類・全剰余類走査・符号上界表を使わない q=0 の排除**。[verify_q0_certificate.py](verify_q0_certificate.py) はこの8個の値と不等式を整数で検算し、実在する距離20の下界符号を正の対照にする。係数を探索した元資料 [lp_exact.py](evidence/agentC-v2/lp_exact.py)・[lp_cert.py](evidence/agentC-v2/lp_cert.py) と各ログも同梱したが、検算では係数探索や単体法を実行する必要はない。

従って q≠0で、D=ker q は二重偶の8次元部分符号、非零語の重みは24以上。最小距離が28以上なら Griesmer 境界により有効長は

\[
\sum_{i=0}^{7}\left\lceil\frac{28}{2^i}\right\rceil
=28+14+7+4+2+1+1+1=58>52
\]

となるので、D は **二重偶 [52,8,24]**。非自明な剰余類 C\D の256語は全て重み22以上かつ2 mod 4で、§7.1 の直接走査により排除する。§7.1 で併せて走査する0 mod 4側は q=0 排除の照合で、主経路の q=0 排除は上の証明書。§7.2 は q≠0 の場合の照合経路として残す。

以下で D は次の3種類だけであることを示し、それらの拡張を全て排除する。

|---|---:|---|
| D0 | 1 | 1+204z^24+51z^32 |
| D1 | 0 | 1+172z^24+32z^28+51z^32 |
| D2 | 0 | 1+174z^24+30z^28+49z^32+2z^36 |

### 3.2. 零列を持つ場合を内部の論法で D0 に帰着する

零列数を z≥1、有効長を n=52−z とする。Griesmer 境界は g_2(8,24)=50 なので、z≤2。零列はどの語の台の外側にもあるため、次のように重み36以上を排除できる。

1. **重み52：** 零列があるので不可能。
2. **重み44：** 台の外側への射影の核は {0,c}。別の核の語 x があれば wt(x)+wt(x+c)=44<48 に反するから。像は次元7のはずだが、有効な外側8−z座標の偶重み空間の次元は7−z≤6で矛盾する。
3. **重み48：** 外側の像の次元は3−z以下なので、核の次元 r は5+z≥6。核では0,c以外が全て重み24であり、c の台48座標で Fourier 反転すると列多重度は48/2^(r−1)。r≥6では整数にならず、矛盾する。
4. **重み40：** 射影の核は {0,c}、像は偶 [12−z,7,≥4]。外側重み j について wt(x)+wt(x+c)=40+2j≥48 なので j≥4。さらに1座標を穿孔すると [11−z,7,≥3] が得られる。Hamming 境界は z=1 で 2^7(1+10)=1408>2^10、z=2 で 2^7(1+9)=1280>2^9 となり、どちらも不可能。
5. **重み36：** 同様に外側は偶 [16−z,7,≥6]。偶で最小距離8以上なら g_2(7,8)=18>16−z に反するので、重み6語が必ずある。その重み6語の台を除く剰余符号は [10−z,6,≥3]。射影の核がその語の張る1次元だけであることと、外側重みが3以上になることは、非零の対の重み和が12以上であることから従う。Hamming 境界は z=1 で 2^6(1+9)=640>2^9、z=2 で 2^6(1+8)=576>2^8 となり矛盾する。

従って非零重みは24,28,32だけ。零列を除いた生成行列で、同じ列の非順序対の個数を b とする。次元8の二元符号について

\[
\sum_{w>0}A_w=255,\qquad
\sum_w wA_w=128n,\qquad
\sum_w w^2A_w=64(n^2+n+2b)
\]

第2モーメントの b は、異なる非零列の2ビットは独立、同一列の2ビットは一致することから得られる。n=51 では A28=−8b なので b=0、A28=0、A24=204、A32=51。n=50 では A28=−40−8b<0 となり不可能。

よって z=1で、零列を除いた D は射影的かつ 8-divisible な [51,8,24]。Kurz **Table 1 の (n,k)=(51,8) の値1** と、同じパラメータ・重み分布を持つ D0 の検算から、D は D0 と同値。§4〜§6 では零列のない D だけを扱う。

## 4. 最大重みを36以下にする

二重偶なので、24以上の候補重みは24,28,32,36,40,44,48,52。

### 重み52

全1語を基底の1本に選ぶと、残る7ビットで表した52列の多重度 m の Fourier 係数は F(0)=52、F(u)=±4（u≠0）。Parseval から Σm²=(52²+127·16)/128=37 となるが、非負整数性から Σm²≥Σm=52で矛盾する。

### 重み44

重み44語 c の外側8座標への射影は、核が {0,c} で次元7。他の核の語 x があれば wt(x)+wt(x+c)=44<48で矛盾する。外側は偶重みだから、射影は偶 [8,7,2] 全体。

外側重みを j とすると、内側44列の Fourier 係数は |F(u)|≤2j−4。非零メッセージの j=2,4,6,8 の個数は28,70,28,1なので、

\[
128\sum m^2\le44^2+70\cdot16+28\cdot64+144=128\cdot39<128\cdot44,
\]

となり矛盾する。

### 重み48

重み48語 c の外側4座標への射影は偶なので、核 K の次元 r は5以上。K の語は0,c以外全て重み24。c を全1の行として Fourier 変換すると列多重度が48/2^(r−1)となるので r=5。K は RM(1,4) の各座標を3回繰り返した符号。

外側重み2の語 x の K 剰余類では内側重みは22か26。各三つ組の重みを r_t、f(t)=3−2r_t とすると、16個の Walsh 係数は全て絶対値4。Parseval から各 r_t は1か2。

外側の基底1100,1010,1001の持ち上げを x,y,z とする。単独と2本の和は全て外側重み2なので、各三つ組で x,y,z の像は F2^3/〈111〉の3つの相異なる非零元。よって x+y+z は各三つ組で000か111。

その外側は1111で、K 剰余類の内側重みは20〜28の範囲、4と3の両方の倍数。したがって全て24となる。16ビットの真理値表が全てのアフィン関数から距離8になることを要求し、Walsh 係数が全て0となって矛盾する。

### 重み40：整数全列挙

外側への射影の核は {0,c} で、像は次元7。内側重みを i、外側重みを j とすると i+j≥24 と 40−i+j≥24 から j≥4。像は偶符号であり、最小距離6以上なら g_2(7,6)=15>12に反するので、偶 [12,7,4]。パリティ検査行列に全1行を選べるので、その12列は F2^4 の16アフィン点から4点を除いたもの。削除4点はアフィン平面型とアフィン独立型の2種類。

この外側符号の双対語は、アフィン関数の台と12点集合との交わり。非零アフィン関数の台は8点または16点なので、双対の最小重みは4以上。従って外側符号の生成行列に零列・重複列はなく、重み j の第1・第2モーメントはそれぞれ768と4992。

外側重み j に対して |F(u)|≤2j−8。上のモーメントを使うと、非零メッセージについて

\[
40^2+\sum_{u\ne0}(2j(u)-8)^2
=1600+4\cdot4992-32\cdot768+64\cdot127
=5120=128\cdot40
\]

Parseval の上界が Σm²≥Σm=40 の下界と一致するので、内側40列の多重度は0/1、全ての非自明係数は上界 ±(2j−8) に達する。

二重偶符号の関数 f(x)=wt(x)/4 mod 2 は3次以下。これは重みの包除展開で、1次項の重みは4の倍数、2次項の交差数は偶数、4次以上の係数は8の倍数になるため。

c と持ち上げ x(u) を基底に選び、a(u)=f(x(u)) とすると

\[
f(x(u)+c)+f(x(u))=j(u)/2\pmod2.
\]

j=4,8,12 で a(u)=0でなければならない。この条件を満たす7変数3次関数は両残余型とも次元8の線形空間。基底の持ち上げを c だけ変える7次元の同値操作で、各型2候補へ縮約できる。

各候補で F(u) の許される符号を入れ、逆 Walsh 変換で m が0/1になるか全列挙する。合同式による消去後の列挙数は4,096+4,096+256=8,448、残り1候補は合同式で直ちに矛盾し、解は0。

**コード：** `exact40.py`、`exact40-results.json`。照合用の bent モデルと8分岐の整数計画モデルでも、OR-Tools・SCIP の両方が不可能と判定しており、異なる帰着による照合になっている。

## 5. 重み36を含む場合

重み36語 c の外側は偶 [16,7,6]。核は {0,c}、外側が4以下なら二つの語の重み和が48未満となる。偶で最小距離8以上は g_2(7,8)=18>16 に反するので、最小距離は6。§2.3 の独立全数分類で確認した3代表を用いる。

### B型とC型の排除

a(u)=wt(x(u))/4 mod 2 は7変数3次以下で、

\[
f(x(u)+c)=a(u)+1+j(u)/2\pmod2.
\]

j=6 では a=0。この線形条件を満たす3次関数空間の次元は B型18、C型19。全関数を列挙し、持ち上げの変更 a↦a+ℓ(u)(1+j(u)/2) と、検証済みの残余符号の座標置換で縮約する。

零列なしの D の同一列対数を b、重み36語数を A36 とすると、最初の2つのモーメントから

\[
A24=172+4b-A36,\quad A28=32-8b+3A36,\quad A32=51+4b-3A36
\]

なので、f の重みは N=32−8b+4A36。c 以外の重み36語を x、その外側重みを j とすると、wt(x+c)=2j≥24 なので j≥12。同じ外側語を持つ対 x,x+c の両方が重み36なら 36+2j=72、従って j=18>16となるので、高々一方しか重み36にならない。よって

\[
A36\le1+\#\{\text{外側語の重み }j\ge12\}
\]

で、B型は1+6+1=8、C型は1+10=11。導関数が1の各対では f の値の一方だけが1となるため、B型は N≥48、C型は N≥56。従って B型は48≤N≤64、C型は56≤N≤76。

実装上は `residual36_cubics.py` が両型に共通の広い範囲48≤N≤76で生成し、B型の上限64は `exact36.py` の持ち上げ前の条件で適用する。C型の下限56は導関数から自動的に満たされる。実際の持ち上げ対象は B型3軌道、C型46軌道。各 a に対し内側重み i は

\[
24\le i+j\le36,\quad24\le36-i+j\le36,\quad i+j\equiv4a(u)\pmod8
\]

を満たす。選択肢は1個か、差8の2個。F(u)=36−2i とし、2択を z_u∈{0,1} で表すと、内側列多重度は逆 Walsh 変換

\[
m(v)=\frac{1}{128}\sum_u F(u)(-1)^{u\cdot v}
\]

で一意に復元される。整数性を mod 8 の線形合同式へ落とし、行消去で得た必要な F2 方程式の全解を列挙する。残る二値自由度は最大12、合計5,318候補で、非負整数多重度になるものは0。多重度の上限2を仮定しなくても0。

**コード：** `residual36_cubics.py`、`exact36.py`、`exact36-results.json`。OR-Tools・SCIP による49モデルも全て INFEASIBLE で一致した。

### A型の構造

外側の全1語の持ち上げとその c との差は、重み32と36。それ以外の外側語から36は出ないので、D の重み36語はちょうど2本。

内側36列の Parseval 上界は Σm²≤38。ただし、全52列の同一列対数 b を直接制限するには、f≠0 と RM(3,8) の最小重みを使えば十分。モーメント式から N=wt(f)=40−8b≥32 なので b≤1、N は32か40。これなら内側の多重度を外側に無条件で適用する必要はない。A型に適合する3次関数は65,536個を全列挙でき、重み40のものは0個（`audit_exact.py`）ので b=1、f の重みは32。

RM(3,8) の最小語の台はアフィン5次元空間なので、その方向部分空間 K の符号次元は5、K は8-divisibleで重み24か32。f=1の剰余類には重み28が30語、36が2語ある。

重み36語を v、そのもう1語を v+k0 と選ぶ。K の列型 p に対する、v のビットに符号を付けた列数の差は、p=0で−5、p≠0かつ k0·p=0で−1、k0·p=1で0。従って K の零列は5以上。一方 Griesmer 境界から K の有効長は47以上で、零列はちょうど5。

K は [47,5,24]、重み分布は1+30z^24+z^32。唯一の重み32語に対応するメッセージを w1 とすると、Fourier 反転により列型は超平面 w1·p=0 の非零15点が各1本、外側16点が各2本、零が5本。前段の v の符号付き列数は、k0·p=1 なら0。一方、単列では符号付き列数は ±1で0にはなれないので、w1·p=0 の全15点で k0·p=0でなければならない。従って k0=w1であり、v は15単列と零列では1、各二重列では0,1に正規化できる。この一致を示してから標準形を使う。

#### 第7行の網羅性：Parseval から bent 関数まで

列型 p を F2^5 で表し、超平面を p=(u,0)、二重列を p=(u,1)、u∈F2^4 とする。第7行 y に対し、列型ごとの符号付き和を

\[
\tau_p=\sum_{j:\,p_j=p}(-1)^{y_j},\qquad
\rho_p=\sum_{j:\,p_j=p}(-1)^{y_j+v_j}
\]

と定義する。K 上の Fourier 変換を T=\widehat\tau、R=\widehat\rho とすると、y+K と y+v+K は f=0 の部分なので全て重み24か32、従って T,R∈{4,−12}。零列5本上の y の重みを r、t=τ_0=5−2r とすれば ρ_0=−t。T の平均が t なので−12の個数は8−2t、R では8+2t。Parseval から

\[
\sum_p(\tau_p^2+\rho_p^2)
=\frac{1}{32}\sum_w(T(w)^2+R(w)^2)=96
\]

15単列は合計30、16個の二重列は合計64をこの左辺に寄与し、零列は2t²を寄与する。従って94+2t²=96で t=±1。y を y+v に替えれば t の符号を変えられるので、t=1、零列上の重み r=2にそろえ、零列の置換でその2点を固定できる。

単列のビットを s(u)（u≠0）とし s(0)=0 を補い、各対のビットを a(u),b(u) とする。4変数の Walsh 変換を

\[
W_a(w')=\sum_u(-1)^{a(u)+w'\cdot u},\qquad
S=W_s(w')
\]

などと書くと、w=(w',ε) に対して

\[
T(w)=S+(-1)^\varepsilon(W_a+W_b),\qquad
R(w)=-S+(-1)^\varepsilon(W_a-W_b)
\]

ε=0,1 の両方で T,R∈{4,−12} を要求すると、可能なのは

\[
(S,W_a,W_b)=(4,\,\pm4,\,\mp4)
\quad\text{または}\quad
(-4,\,\pm4,\,\pm4)
\]

だけ。従って s,a,b は全て bent。双対を W_a=4(−1)^ã などで定めると、条件は **ã+b̃+s̃=1** と同値。逆にこの関係を満たす bent 関数からは上式の T,R が全て4か−12になり、必要な重み条件が全て満たされる。

4変数 bent 関数は全て二次以下であり、これは全65,536真理値表でも確認済み。K の加算は a に任意のアフィン関数を加えるので、a の一次・定数項を消して純二次 bent 関数 L を選べる。その L は28個。B=s̃、h=1+L̃ と置けば b̃=B+h で、s(0)=0 は wt(B)=6 と同値。従って `normalized36_orbits.py` は28個の L と448個の重み6の bent 関数 B を並べ、B+h も bent になるものを全て取ればよい。各 L に192個、合計 **5,376個**。逆方向も成り立つ上の導出により、この列挙は全候補を尽くす。

独立な確認として、査読 B は単列の符号2^15通りと、許される Fourier 値を全列挙して逆変換する `verify_A7_count.py` により、零列パターン固定で **172,032=5,376×32**、K の加算を除いて5,376を得た。これは bent 関数の二次性に頼らない個数確認。元の5,376候補が全て有効で、K を法として互いに異なることも確認されており、個数一致と合わせて網羅性の独立な照合になる。[B2 §1(1)](review/v1/B2.md)

#### 第8行と同値類

第7行の5,376候補は、符号を保つと検査した座標置換により1軌道。第8行も上と同じ形に正規化でき、零列5本上の重み2パターンは、第7行の2点集合とちょうど1点で交わる6通りを調べれば足りる。交差数が0なら2行の和の零列重みは4、交差数が2なら0となり、同じ Parseval による重み2または3の必要条件に反するから。既存7行の加算を除く第8行候補は36個で、全て1軌道。査読 B は著者の置換群を使わず、基底対応による全語の重み保存を検査して、第7行の1軌道と第8行の1類を独立に確認した。したがってこの型の D は D2 の1種類だけ。[B2 §2](review/v1/B2.md)

**コード：** `normalized36_orbits.py`、`normalized36-classification.json`。

## 6. 最大重み32の場合

f=wt/4 mod 2 が0なら8-divisible。この場合、モーメント式 A28=32−8b と A28=0 から **b=4** で、D は重複列を持つ非射影的な符号。Kurz Table 1 は重複列を許す分類（§2.1）なので、零列なし・有効長52・次元8・最小距離24のこの D にも適用でき、**(n,k)=(52,8) の値0** で除外される。f≠0なら RM(3,8) の最小重みから wt(f)≥32。

上記モーメント式に A36=0を代入すると wt(f)=32−8bなので、b=0、wt(f)=32。f=1の台はアフィン5次元空間、その方向の K は次元5で重み24か32、剰余類は全32語が重み28。

定重み剰余類の Fourier 変換から、K の非零列多重度は偶数、零列数は4以上。非零多重度を半分にして Griesmer 境界を使うと零列数は4以下となり、ちょうど4。半分にした符号は [24,5,12]、重み分布1+28z^12+3z^16。

その列多重度の整数性から、重み16を持つ3メッセージの和は0。従って24列は F2^5 の固定3次元部分空間 U の外側の全点。K はこれらを2回ずつ並べ、零列を4個加えた形に一意に正規化できる。

f=1の代表 v は、各二重列で0,1、零列4個で全1。以下で残る行の零列上の重みも導く。

### 第7行の網羅性：零列と Fourier 支持

第7行を y とし、§5 と同じく列型ごとの y、y+v の符号付き和を τ_p,ρ_p とする。K の二重列は P=F2^5\U の24点に対応し、零列4本上の y の重みを r とすれば τ_0=4−2r=t、ρ_0=−t。y+K、y+v+K の全語は重み24か32なので、§5 と同じ Parseval 計算で Σ_p(τ_p²+ρ_p²)=96。24個の対だけで24×4=96を寄与し、零列が2t²を寄与するので t=0、**r=2**。

各対の y のビットを a(p),b(p) とし、

\[
g(p)=\frac{(-1)^{a(p)}+(-1)^{b(p)}}2,\qquad
h(p)=\frac{(-1)^{a(p)}-(-1)^{b(p)}}2
\]

を P 上で定義し、U 上では0とする。すると g,h∈{0,±1} で、P 上で両者の台は互いに補集合。τ=2g、ρ=2hなので、重み24/32の条件は **ĝ,ĥ∈{2,−6}** と同値。逆にこの条件と台の補集合条件を満たす g,h からは、各対の a,b が一意に復元される。

W=U^⊥ と置けば dim W=2で、g が U 上で0であることから、任意の α について

\[
\sum_{w\in W}\widehat g(\alpha+w)
=4\sum_{p\in U}g(p)(-1)^{\alpha\cdot p}=0
\]

W の各剰余類には4点あり、ĝ の値が2と−6だけなので、**−6は各剰余類にちょうど1点**。従ってその台 S は、商 F2^5/W≅F2^3 から W≅F2^2 への関数 φ のグラフ。これはグラフであることを仮定した縮約ではなく、Fourier 条件からの帰結。

座標を S={(u,φ(u)):u∈F2^3} と取ると、p=(α,β)、β≠0 に対する逆変換は

\[
g(\alpha,\beta)=-\frac14
\sum_{u\in\mathbb F_2^3}(-1)^{\alpha\cdot u+\beta\cdot\varphi(u)}
\]

g∈{0,±1} なので、φ の2成分およびその和の Walsh 値は {0,±4} に入り、全て3変数 semi-bent。3次の3変数 Boolean 関数は真理値表の重みが奇数で、アフィン関数を加えても奇数のままなので、Walsh 係数が2 mod 4となりこの条件を満たせない。従って次数は2以下。またアフィン関数は Walsh 係数±8を持つので除かれ、2成分の純二次部分 qa,qb は、非零かつ相異ならなければならない。

### h を同じ二次部分の組と組み合わせる理由

β≠0 を固定した各スライスでは、g の台は非零3変数二次形式の Walsh 支持であり、4点のアフィン平面。その平面の方向は二次形式の極化交代形式の1次元の根基で決まる。h の台がその補集合になるには、h 側の平面が同じ方向でなければならず、根基は一致する。F2^3 上では非零交代形式7個と1次元部分空間7個が根基によって一対一に対応するので、純二次部分も一致する。β=(1,0),(0,1) に適用すると、h 側も同じ組 **(qa,qb)** になる。一次・定数項は別に全列挙しており、この一致からそれらまで同一とはしない。

非零の純二次部分7個から相異なる順序対を選び、各成分のアフィン部分16通りずつを加えると、g は7×6×16²=10,752個。同じ二次部分を持ち、台が補集合になる h を全て組み合わせると、第7行は **344,064候補**、K の32個の加算を除くと **10,752候補**。各候補は全重み条件を直接検査し、K を法として重複を除いている。

独立な網羅性確認として、査読 A・B は二次性を使わず、W の8剰余類それぞれで−6の位置を選ぶ **4^8=65,536通りの φ** を全て逆変換した。{0,±1} 値になるものと、互いに補集合の台を持つ組を全て取り、同じ344,064候補・商10,752候補を得た。元の候補の有効性と商での相異性も別途確認している。[A1 §(2)](review/v1/A1.md)、[B2 §1(2)](review/v1/B2.md)

### 第8行と同値類

第7行の10,752候補は、検証済み座標置換で全て1軌道。第8行の零列上の重みも2で、2行の和にも同じ条件が必要なので、第7行の2点集合との交差数は1。その外側パターン4通りを調べ、7行の加算を除くと24候補、全て1軌道。査読 B の基底対応による独立な同値検査でも、第7行は1軌道、第8行は全て D1 と同値だった。従って D は D1 の1種類だけ。[B2 §2](review/v1/B2.md)

**コード：** `normalized32_orbits.py`、`normalized32-classification.json`。自己同型群の完全な位数や既成の同値判定ソフトには依存せず、使用する置換が符号を保つことを実際に確認している。

### 7.1. 全剰余類の直接走査による主経路

§3〜§6 により、調べる二重偶 [52,8,24] は D0,D1,D2 の3類。[D0](D-representative-0.txt)・[D1](D-representative-1.txt)・[D2](D-representative-2.txt) はいずれも階数8・二重偶・最小距離24で、零列数と同一列対数 (z,b) はそれぞれ (1,0),(0,0),(0,1)、重み分布は §3 の表の通り。これらは §3.2・§5・§6 で一意性を示した各場合の条件を満たすので、各ファイルが対応する唯一の類を代表する。[検算記録](AUDIT.json)

C⊃D≅Di なら、その同値を与える座標置換を C 全体にも施すことで **C=〈Di,v〉、v∈Di^⊥、wt(v) 偶** の形になる。従ってこの3代表からの拡張を調べれば十分で、代表の由来を知るために §7.2 を使う必要はない。それぞれ dim D^⊥=44、D⊆D^⊥ なので dim(D^⊥/D)=36。D の基底を D^⊥ の基底に延長して補空間 V を取ると、**V の2^36個の元が各剰余類 v+D のちょうど1個の代表**になる。v∈D^⊥ であることは構成で保証され、〈D,v〉が自己直交である条件は wt(v) が偶数であること。

| D1 | 0 | 0 |
| D2 | 0 | 0 |

### 7.2. 反射と軌道縮約による照合経路

この節は q≠0、すなわち非自明剰余類の全語の重みが2 mod 4となる場合を扱う。q=0 の場合は §3.1 の証明書で排除し、§7.1 の直接走査でも照合している。

D0 の51非零座標は、生成行列の3列の和が0となる17個の三つ組に分かれる。v∈D0^⊥ の偶重み代表を、各三つ組で偶重みの部分 a、三つ組111の加算、最後の座標に一意分解する。

a の空間は、D0 による商を取ると18次元。三つ組111を加える17ビットにより最後の座標の偶奇も決まる。実際に符号と三つ組を保つ座標置換で18次元側を縮約すると23軌道。より小さい **j↦j+1 と j↦2j（mod 51）が生成する位数408の非巡回群 Z51⋊〈2〉** では695軌道となり、固定 D0 の別の全探索にも用いた。座標51は固定し、2の mod 51 での位数は8。

偶重み h に対する直交変換

\[
T_h(x)=x+(x\cdot h)h
\]

は内積を保つ。wt(h)=6なら、偶重み語の重み mod 4も保つ。D0 の零座標を含む重み6の h で距離24を保つものは29,376通り。D1 と D2 はこの中に含まれ、具体的にはビットマスク

```
h1 = 2251816993685511
h2 = 2251834173685767
```

を用いる。座標番号は0始まり、元の零座標は51。h1 の台は {0,1,2,17,34,51}、h2 の台は {0,1,2,18,35,51}。T_h1(D0) は零列なしで重み集合 {24,28,32} なので §6 の一意性から D1 類、T_h2(D0) は重み36を持つので §5 の分類から D2 類。両者の重み分布・零列数の検査に加え、査読 B は `th_equiv.py` で基底を対応させた全語の重み保存を検査し、直接にも同値を確認した。[v1 B1 の §7 T_h の項](review/v1/B1.md)、[v1 B2 (3)](review/v1/B2.md)

軌道縮約に用いる群を G とする。使用する各座標置換は D0 とその三つ組を保ち、座標51を固定すると確認している。許される h の集合は「座標51を含む重み6、かつ T_h(D0) の最小距離が24以上」で定義されるので G 不変。また

\[
gT_hg^{-1}=T_{gh}\qquad(g\in G)
\]

従って v の18次元側を軌道代表に移しても、17ビット側を全列挙し h を全29,376個調べれば、元の (v,h) と同値な対を必ず含む。v と h を別々の軌道代表に固定する縮約は行わない。

T_h の前後で偶重み語の重み変化は−4,0,+4だけ。従って目標の拡張の逆像は、剰余類の最小重み18以上。23軌道を全て処理して、この条件を満たす代表985,908個を列挙した。各代表について29,376個の h のうち、

- 重み18の各語との交差が1。
- 重み22の各語との交差が5でない。

という必要十分条件を満たす h を調べ、0個だった。重み26以上は変換後も22以上なので追加条件は不要。

このため D1 と D2 からの目標拡張はない。D0 からの拡張も `triple_exhaustive.py` で全排除済み。D0 による偶重み商のうち2 mod 4の全 2^34+2^17 個を軌道のサイズで数え直し、範囲の一致を確認した。

**コード：** `triple_search.py`、`geometry.py`、`triple_exhaustive.py`、`joint_switch_search.py`。

## 8. 下界と結論

D0 に長さ52の全1行を加えれば SO [52,9,20]。全512語を検算すると

\[
W=1+51z^{20}+204z^{24}+204z^{28}+51z^{32}+z^{52}
\]

生成行列は `LOWER-52-9-20.txt`、階数9・自己直交性・最小距離20は `AUDIT.json` に記録した。

q=0 は §3.1 の証明書、q≠0 は §3.2〜§6 の分類と §7.1 の直接走査で排除するので、最小距離22以上の SO [52,9] は存在しない。SO 符号の全語は偶重みだから、最小距離21も不可能。下界20と合わせて **d_SO(52,9)=20**。

## 9. 再現・検証上の境界

- 主経路 §7.1 の全数走査は C/GCC/OpenMP。査読時の環境は Docker `gcc:14`、OpenMP 16スレッドで、原実装の所要時間の目安は T=22 が1類あたり約1〜5分、D0 の T=20 が約3〜8分。計算機と負荷で変わる実績値で、新しい範囲指定実装の全走査時間は測定していない。
- 分類・ヘッダー生成・記録には Python 3.10以上を使う。著者側の分類は NumPy 2系（`bitwise_count`）、[16,7,6] の明示置換検査は NetworkX を使う。v3 の限定検査は Python 3.13 と Docker `gcc:14` の2スレッドで通過した。再現の主経路は最適化ソルバーを呼ばず、OR-Tools・pynauty は別方式の照合用。
- [reproduce.py](reproduce.py) は既定で限定検査。`--full` は [16,7,6] の4分割の明示置換検査、§4〜§6 の分類、§7.1 の4全走査（3類 T=22、D0 T=20）、下界検算を実行し、全数値が一致した場合だけ `full_proof_reproduced: true` と記録する。§7.2 を追加で再実行する場合だけ `--legacy-cross-checks` を付ける。詳細は [README](README.md)。
- [限定検査記録](runs/v3-bounded-check/REPRODUCTION-V3.json) は `bounded_checks_passed: true`、`full_proof_reproduced: false`。小さい符号3例の全剰余類を周囲空間の総当たりと比較し、各 Di の4,096代表、D0 の距離20の既知剰余類を検査した。q=0 の証明書は固定係数で整数検算した。**長い全走査・[16,7,6] の全同値判定・旧反射経路は v3 改訂作業では再実行していない**。
- 合同式消去の小さい320問題での総当たり照合、4変数の全真理値表、標準形からの60行列、下界などの既存記録は [AUDIT.json](AUDIT.json)。主経路の新しい実装の限定検査を、査読時の全走査の再実行として数えない。
- v2 の査読判定は「要修正（文書）」であり、v3 が再査読で承認されたとは主張しない。Kurz Table 1 の2値は既知の外部分類結果として使い、その分類を再計算していない。Simonis 本文、Bouyukliev Table 8、一般符号の上界表は主経路で使わない。
- 同梱原資料は [SOURCE-MANIFEST.json](SOURCE-MANIFEST.json) に元の場所・SHA-256・サイズを記録し、引用は配布物内の相対パスにした。[evidence/INDEX.md](evidence/INDEX.md) に役割と再実行上の注意をまとめた。原資料は変更せずに保存したので、その中の歴史的な絶対パスや `/w` の作業ディレクトリを現在の実行入口とは混同しない。
- 元の [REPRODUCTION.json](REPRODUCTION.json) と既存 ZIP は v1 の計算記録・配布物のまま。v2 時点の README・実行入口・manifest は [history/v2](history/v2/) に保存し、v3 のファイルは [MANIFEST.json](MANIFEST.json) に記録する。新しい実行は `runs/` 以下の別ディレクトリを作り、過去の結果を上書きしない。
