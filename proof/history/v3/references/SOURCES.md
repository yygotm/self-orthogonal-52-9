The package uses the published classification values, not a recomputation of
that classification. Its table includes minimum distance at least 24. For
k=8 and n<=54, an 8-divisible code cannot have minimum distance >=32 because
the Griesmer bound is 65, so the two entries also apply to exact distance 24.
