## 5. 自分の誤判定の可能性

- **Kurz の k=8 行は再計算していない。** 「Table 1 は非射影的な符号を数える」は、k=1,2,3 行の一致と Lemma 1 の書き方からの推論である。同じ表の全ての行が同じ生成法で作られたという前提に依る。
- **表の列の対応。** `pdftotext -table` の列の並びに依っている。k=1,2,3 行は私の計算と全て一致したので、対応は正しいと判断した。k=8 行の「1 0 0 1」を n=51〜54 に当てるのは、v1 の B1 の読みと同じである。
- **§7.1 の 2^36 走査は、私自身では回していない。** プログラムの論理は読んで確かめ、header は再生成して照合し、小さい類似問題で総当たりと一致させた。実行結果は Agent C・`ext52x`・前任 B の記録に頼った。
- **小さい類似問題の範囲。** n=28,30、次元8、d=8,12 で、n=52 より小さい。64ビット演算の範囲や重み分布の形の違いによる不具合は、n=52 での抜き取りで補っただけである。
- **§5・§6 の内部の導出。** 手で追ったが、形式化はしていない。標準形への正規化の細部は A の担当範囲で、v1 の B2 の計算に頼った箇所がある。
- **`classify16_7_6.py` の再実行。** 前任 B のコードをそのまま実行したので、論理の独立性は無い。class52 の別方式が、独立性の主な支えである。
